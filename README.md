# BEA-GS: BEyond rAdiance supervision in 3DGS for precise object extraction

Project page for the paper **BEA-GS: BEyond rAdiance supervision in 3DGS for precise object extraction**.

Paper: https://arxiv.org/abs/2605.09662

## Media to add

This page was scaffolded from the [IReNe](https://github.com/IVIazz97/irene) project page. The IReNe-specific
media has been removed. Drop in the BEA-GS assets at:

- `static/videos/results/result_1.mp4`, `result_2.mp4`, `result_3.mp4` — result carousel clips
